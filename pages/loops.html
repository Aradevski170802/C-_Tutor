Lesson 4

Loops: for, while, and do-while

A for loop has three parts: a starting point, a condition checked before every lap, and a step that runs after every lap. Watch the counter i walk across the array while the loop body runs once per element.

while and do-while can do the exact same job as a for loop — they're just written differently, and one of them has a genuinely different rule for when the body runs at all. All three appear further down this page, doing the same sum, so you can compare them directly.

1Summing an array with a for loop

for vs. foreach vs. while vs. do-while: use for when you need the index itself (or want to skip/step in a custom way); use foreach (var x in items) when you just need each value, in order, and don't care about the index; use while when the number of laps isn't known ahead of time; use do-while when the body needs to run at least once no matter what.

2The same sum, with a while loop

A while loop is a for loop with its three parts split apart: the counter is set up before the loop, the condition is the only thing in the parentheses, and the step happens as the last line inside the body. Same numbers, same result — just arranged differently.

3do-while: the body always runs at least once

The one real difference: a while loop checks its condition before the first lap, so it can skip the body entirely. A do-while loop checks after the first lap, so the body always runs at least once — even if the condition was already false to begin with. Try setting the start value to 3 or higher below.

4Nested for loops: walking a 2D array

Why this matters

  • Off-by-one errors are the classic loop bug — using <= instead of < reads one element past the end of the array.
  • The outer loop in a nested loop picks the row; the inner loop finishes completely before the outer loop advances to the next row.
  • A nested loop over an n × m grid runs the inner body n × m times — costs add up fast with more rows/columns.
  • Forgetting the step (i++) inside a while loop is a classic beginner bug — the condition never changes, and the loop runs forever.
  • do-while needs a semicolon after the closing while (...) — it's the only loop in C# that ends with one.
