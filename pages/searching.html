Searching an Array

The simplest way to find a value is a linear search: start at index 0 and check every element in order until you find a match — or run out of elements.

Faster search: if an array is already sorted, you can use binary search instead — repeatedly check the middle element and discard half the remaining elements each time. It finds things in O(log n) time instead of O(n), but only works on sorted data.

Why this matters

  • Linear search always works, sorted or not — it just checks everything.
  • Worst case for linear search is checking every single element (the value is last, or missing entirely).
  • In real C# code, Array.IndexOf(arr, value) and list.Contains(value) do a linear search for you.
  • Searching a 2D array means a loop inside a loop — the outer loop picks the row, the inner loop scans that row's columns.
