Lesson 6

Functions (Methods)

A method is a named, reusable block of code. Values go in as arguments, get copied into the method's parameters, the body runs, and a single value can come back out as the return value.

1Following a value through a method call

Parameters are copies (for value types): changing a or b inside the method does not change the caller's original variables — int, double, and bool are passed by value. Objects and arrays are passed by reference to the same underlying data, which behaves differently.

2The call stack: a method calling itself

Every method call gets its own frame stacked on top of the previous one. The frame at the top is whatever is currently running; frames below are paused, waiting for the call above them to return.

Why this matters

  • Return type comes before the method name: int Add(...) returns an int. Use void if it returns nothing.
  • A method that calls itself is recursive — it needs a base case (a condition that stops the recursion) or it will call itself forever and crash with a StackOverflowException.
  • Breaking code into small, well-named methods makes it far easier to read, test, and reuse than one giant block of code.
