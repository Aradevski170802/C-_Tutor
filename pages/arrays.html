Arrays & Inserting Elements

An array is a fixed-size row of boxes, each holding one value, numbered from index 0. "Inserting" into the middle isn't magic — every element after the insertion point has to physically shift over to make room.

Key fact: an array's size is fixed the moment it's created with new — there's no method that makes it bigger. To "insert" a value, you create a brand new array one slot larger, copy the old values across, and drop the new value into the right place. That's exactly what you're about to watch happen.

Shortcut: C# actually has a built-in method for exactly this "make a bigger array and copy everything over" pattern: Array.Resize(ref numbers, numbers.Length + 1); does the copy for you. It's still just an array underneath — no new insert logic, just less typing.

2Removing an element (shift left)

Removal is the mirror image of inserting: everything after the removed spot shifts one step to the left. The array still can't shrink, so the last slot is left holding a leftover/default value.

Why this matters

  • Indexing starts at 0. The first element is array[0], not array[1].
  • Fixed-size arrays (int[] nums = new int[5];) have their size baked in the moment you create them with new — they're fast and memory-efficient precisely because that size never changes.
  • Both inserting and removing mean shifting every element on one side of the change — that's an O(n) operation, not instant, no matter which direction you shift.
  • Array.Sort and Array.Reverse mutate in place — they change the array you pass in rather than returning a new one, unlike a method such as Substring on a string.
  • Array.Sort only sorts ascending — there's no built-in "descending" option. The standard trick is Array.Sort(numbers); Array.Reverse(numbers); — sort it the normal way, then flip it.
