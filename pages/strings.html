Lesson 5

Strings

A C# string behaves a lot like a read-only array of characters — you can index into it and loop over it — but with one crucial difference: strings are immutable. No method ever changes a string in place; every one of them hands you back a brand new string.

Why this matters

  • Immutability means str.ToUpper(); on its own line does nothing useful — you must capture the return value: str = str.ToUpper();
  • foreach (char c in text) is the simplest way to visit every character in order.
  • StringBuilder exists specifically for building up a string piece by piece efficiently, without creating a new string on every single change.
  • string.Length gives the character count — valid indexes run from 0 to Length - 1.
