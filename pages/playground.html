Write, Test & Submit Your Code

Write some C# below, actually run it to make sure it works, then send it to your teacher. Three steps, in order — don't skip the testing step.

1Write your code

Start from the template below, or clear it and write your own. This box is just for writing — it doesn't run anything itself.

2Test it for real

This site can't run C# by itself, so testing happens on a real online compiler. One click copies your code and opens it in a new tab — press Ctrl+V (or Cmd+V on a Mac) once it loads, then hit that site's Run button. Fix anything that doesn't work before moving on.

3Submit it to your teacher

Only submit code you've actually confirmed runs in step 2. This opens your email app with everything filled in — you just hit send.

Heads up: very long code can get cut off by some email apps when it's stuffed into a link like this. If your email looks like it's missing the end of your code, just copy the rest in manually before sending.
