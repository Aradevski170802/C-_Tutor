Lesson 2

2D Arrays

A 2D array is a grid: rows and columns, addressed as grid[row, col]. Think of a spreadsheet, a chessboard, or a seating chart — anything laid out in rows and columns is a natural fit. Like a normal array, a rectangular 2D array (int[,]) has a fixed size in both directions — you can overwrite a cell, but you can't "grow" the grid itself.

Before touching cells, a 2D array needs to tell you its own shape. GetLength(0) is the number of rows, GetLength(1) is the number of columns — get that order backwards and you'll loop off the end of the array or miss entire rows without any error message warning you.

This lesson works through the full lifecycle of a grid: creating and filling one, measuring it, writing into a specific cell, running totals across it, and the two situations where a grid's fixed shape actually gets in your way.

1Declaring and filling a grid

new int[3, 4] reserves a 3-row, 4-column grid where every cell starts at 0 — exactly like new int[5] gives you five zeros for a 1D array. A nested loop is the standard way to fill it: the outer loop walks the rows, the inner loop walks the columns of whichever row it's on.

2Measuring the grid: GetLength(0) and GetLength(1)

GetLength(0) counts how many rows there are by counting downward. GetLength(1) counts how many columns there are by counting across the first row. Watch the sweep for each one below.

Jagged arrays are different: a jagged array (int[][] grid = new int[3][];) is really an array of separate arrays, so it has no single "column count" — use grid.Length for the number of rows, and grid[i].Length for the length of row i specifically, since each row is free to be a different size. What about inserting a new element, with a shift? A row of a 2D array is just as fixed-length as the grid itself, so it behaves exactly like the removal you'd do on a plain 1D array: shift the values within that row, and the last value in the row gets overwritten — there's no room to grow into.

6Jagged arrays: rows with different lengths

Sometimes rows genuinely aren't the same length — Pascal's triangle below is a classic example: row 0 has 1 number, row 1 has 2, row 2 has 3, and so on. A rectangular int[,] can't represent that without wasting space on empty cells, so this calls for a jagged array: int[][], an array where each element is its own separate, independently-sized array.

Why this matters

  • Rectangular array int[,] grid = new int[3, 5]; — one block of memory, every row the same length. Good for grids, boards, and images.
  • Jagged array int[][] grid = new int[3][]; — an array of arrays, where each row can be a different length. Good for triangles, adjacency lists, or any data that isn't naturally rectangular.
  • Access order: grid[row, col] — row first, then column. Mixing them up is a very common beginner bug, especially on non-square grids where the mistake doesn't crash, it just silently reads the wrong cell.
  • Nested loops mirror the grid: the outer loop's variable is almost always the row, the inner loop's variable is almost always the column — keeping that convention makes someone else's grid code much easier to read.
  • If you truly need a row to grow, you're back to the same trick as Lesson 1: build a new, longer array for that row and copy the old values across.
