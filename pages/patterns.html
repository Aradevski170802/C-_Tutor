Lesson 7

Practice Patterns

These are the exercises almost every C# beginner is asked to write at some point — not because the output matters, but because writing them forces you to actually think in loops, conditions, and accumulation. Once these feel easy, loops in general will too.

1Sum of 1 to N

A running total, updated once per lap of the loop. This exact shape — a variable started at 0 before the loop, updated inside the loop — shows up constantly: totals, counts, averages, products.

sum = 0
Shortcut: the sum of 1 to N also has a direct formula, n * (n + 1) / 2 — no loop needed. It's a good example of why it always pays to ask "is there a smarter way?" once the loop version works.

2FizzBuzz

For every number from 1 to N: print "Fizz" if it divides evenly by 3, "Buzz" if it divides evenly by 5, "FizzBuzz" if it divides evenly by both — and the number itself otherwise. It's really just an if / else if chain running inside a loop.

3Print a triangle of stars

A classic nested-loop exercise: the outer loop picks which row you're on, the inner loop prints that many stars before moving to a new line. Row 1 prints one star, row 2 prints two, and so on.

Why this matters

  • Accumulator pattern: a variable set up before a loop and updated inside it is the basis of almost every "total", "count", or "build a result" piece of code you'll ever write.
  • FizzBuzz is famous as a quick interview screen precisely because it needs a loop and a small chain of conditions used correctly together — nothing more, nothing less.
  • Nested loops for shapes (triangles, grids, checkerboards) are the same skill as nested loops over a 2D array — the outer loop is the row, the inner loop is what happens within that row.
  • Try changing N and stepping through by hand before hitting Play — predicting the next line is the whole point of the exercise.
